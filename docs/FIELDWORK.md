# Fieldwork guide: organizing on-site mapping data / Gabay sa fieldwork

How NSTP group members can record what they find on site so it goes straight into the map.
(Maikling gabay kung paano i-record ang nakita sa site para direkta itong mapunta sa mapa.)

## 1. Pick the right "type" of entry

| Thing on site | Category to choose | Drawn as |
|---|---|---|
| Building / establishment / tourist spot / school / health center / barangay hall | Tourist spot, School, Healthcare, Government, Public space | Pin |
| Stand-alone PWD ramp, restroom, entrance, signage | PWD ramp, Accessible restroom, Accessible entrance, Signage | Pin |
| Sidewalk, pedestrian crossing, street/road stretch | Sidewalk, Pedestrian crossing, Street | **Line** (tap points along it) |
| Public transport stop | Public transport / stop | Pin |

Tip: for a building, make ONE pin and list every accessibility feature inside it under
**Accessibility features** (ramp, entrance, restroom, signage, PWD parking…), each with its own status.
Use a separate pin only when a feature stands alone on the street (e.g. a crossing).

## 2. Pick the status (color + shape)

| Status | Pin | Use when |
|---|---|---|
| Existing accessibility feature | green circle ✓ | Present and usable |
| Needs improvement | orange ! | Present but has barriers (steep ramp, damaged/obstructed sidewalk, restroom not accessible) |
| Proposed infrastructure | blue square + | Not there yet; recommended (new ramp, crossing, restroom) |
| Needs further assessment | gray ? | Not enough info; needs measurements/photos |

The pin's status is the overall verdict. The per-feature statuses give the detail.

## 3. What to capture at each stop (on the phone)

1. Log in (`/login`) → **Add location**.
2. Stand at the spot → **Use my current location** (or tap the map / drag the pin). For lines, walk and tap **Use my current location** at each corner, or tap the map.
3. Name, category, status.
4. **Add a feature** for each ramp/entrance/restroom/etc. with a short note (e.g. "slope looks too steep", "door width ~80 cm").
5. Fill **Existing accessibility features**, **Barriers / missing facilities**, **Recommended improvements**.
6. **Add photos** (taken on site; the app shrinks them automatically). One wide shot + one close-up of each barrier.
7. **Source / fieldwork notes**: who surveyed, date, tools used.
8. Save.

## 4. Naming and consistency rules

- Name = what people call it ("Real Elementary School", "Sidewalk – National Hwy near Calamba Medical Center").
- Write notes in English or Filipino; either is fine. Keep measurements in cm / %.
- One surveyor per place; note the date in the Source field.
- Do not delete places still being assessed; set them to "Needs further assessment".

## 5. Backing up / analysing the data

On the map's list page: **Download data (CSV)** (opens in Excel / Google Sheets) and
**Download map data (GeoJSON)** (opens in QGIS, Google My Maps, etc.). Download a copy after each fieldwork day.

## 6. Language

The site has an **FIL / EN** button. It translates the menus and labels; the notes that editors type stay as typed.
